🔌 What is XLPro Integration?

XLPro Integration is a bridge that connects two powerful systems:

System Connection
┌─────────────────────────────────────────────┐ │ Xuber Enterprise │ │ (Insurance Claims & Underwriting) │ └────────────────┬────────────────────────────┘ │ │ XLPro Integration │ (Data Bridge) │ ┌────────────────▼────────────────────────────┐ │ GLOBAL XLPro │ │ (Reinsurance Management) │ └─────────────────────────────────────────────┘

Why does this matter? These two systems need to share information automatically. Without integration, teams would have to manually copy data from one system to another — which is slow, error-prone, and inefficient.

💡 Think of it like...
Two departments that used to pass paper files back and forth. Integration sets up an automated mail system so documents arrive instantly and accurately.
  • Eliminates manual data entry
  • Reduces human error
  • Speeds up claim processing
  • Keeps systems synchronized 24/7

🌍 What is GLOBAL XLPro?

What does "ceded reinsurance" mean? ▼
Imagine you're an insurance company. You insure 1,000 houses, but that's risky — if a hurricane hits, you'd have to pay out millions. So you buy insurance FROM another company to cover half those houses. That's reinsurance. "Ceded" means the risk has been transferred to another insurer.

GLOBAL XLPro is specialized software for managing reinsurance relationships.

Feature What It Does
Contract Management Tracks reinsurance contracts and coverage
Claim Routing Identifies which claims are covered by reinsurance
Recovery Calculation Calculates how much money the company recovers
Financial Reporting Creates reports for management and regulators
🎯 Why integrate Xuber with XLPro?
When a claim is created in Xuber, the reinsurance team instantly knows: "Is this claim covered by our reinsurance? How much can we recover?" This information is critical for financial planning.

🔄 How Data Flows

Integration Data Flow (Step by Step)
Step 1: Claim Created in Xuber │ ▼ Step 2: Message Sent to Messaging Server │ ▼ Step 3: Data Arrives in Staging Database │ ▼ Step 4: Data Validated & Checked │ ▼ Step 5: Approved Data Moves to XLPro │ ▼ Step 6: XLPro Knows About the Claim!

Each step is automated. The entire process typically takes 15-30 minutes from claim creation to XLPro visibility.

What happens in the staging database? ▼
The staging database is like a quality control checkpoint. Data arrives here first, where it's checked for errors: "Is this a valid claim? Are all required fields filled? Are the numbers reasonable?" Only data that passes all checks moves to XLPro. This protects the reinsurance system from bad data.

🏗️ Integration Architecture

3 Main Components
1️⃣ XLPro Integration Service — on Xuber Enterprise Server ▼
This is installed on the Xuber server. It monitors Xuber for new claims and prepares them to be sent to XLPro. Think of it as the "sender" that packages data for shipment.
2️⃣ Messaging Module — on Xuber Messaging Server ▼
This is the "postal service" between Xuber and XLPro. It takes the packaged data and delivers it to the staging database. It's responsible for reliable message delivery.
3️⃣ USM 6-9 Load — on XLPro Database Server ▼
This processes incoming messages and loads them into GLOBAL XLPro. It's the "receiver" that unpacks the data and stores it where XLPro can use it.

⚙️ Key Components You'll Encounter

SSIS Packages — Automated Data Movement Jobs ▼
SSIS stands for SQL Server Integration Services. These are automated jobs that run on a schedule (e.g., every 15 minutes). They handle the actual data movement between databases. Two key packages: USM2Staging (Xuber → Staging) and Staging2XLPro (Staging → XLPro).
Configuration Files — Instructions for SSIS Packages ▼
Config files (.dtsConfig) tell SSIS packages where the databases are and how to connect to them. They contain connection strings, database names, folder paths, and passwords. Think of them as "address books" for the integration.
Service Accounts — Security & Permissions ▼
Integration services run under dedicated user accounts with limited permissions (not admin accounts). This is a security best practice. These accounts have access only to what they need: specific databases and folders. Nothing more.

📋 What You Need Before Installing

System Requirements

  • GLOBAL XLPro version 2.8.30 or later
  • Xuber Enterprise with messaging components
  • Microsoft SQL Server (supported version)
  • SQL Server Integration Services (SSIS)
  • MSDTC (Distributed Transaction Coordinator)

Access & Permissions

  • Administrator access to SQL Server
  • Admin rights on Xuber servers
  • db_owner permissions on databases
  • Access to installation media
⚠️ Critical Step
Back up all databases before starting installation. If something goes wrong, you can restore from backup. Never skip this step.

🚀 Getting Started (5 High-Level Steps)

Installation Sequence
Step 1: Back up databases │ Step 2: Update XLPro database with integration schema │ Step 3: Update Xuber database with integration config │ Step 4: Install XLPro Integration on Xuber server │ Step 5: Configure and schedule SSIS packages │ ✓ Integration is Ready!

Estimated time: 2-4 hours depending on system complexity and experience level.
