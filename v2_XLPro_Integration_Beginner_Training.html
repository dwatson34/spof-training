Beginner Level — Understanding GLOBAL XLPro Integration with Xuber Enterprise

What is XLPro Integration?

XLPro Integration connects two systems:

  • Xuber Enterprise — An insurance platform handling claims, underwriting, and reporting
  • GLOBAL XLPro — A ceded reinsurance solution for managing reinsurance business

When these systems work together, they can share data automatically, eliminating manual data entry and reducing errors.

Key Concept: Think of XLPro Integration as a bridge between two buildings. Data flows across the bridge in both directions, keeping both systems synchronized.

Why does this matter? Reinsurance teams can manage claims and data in Xuber while XLPro automatically receives updates, eliminating copy-paste errors and delays.

What is GLOBAL XLPro?

GLOBAL XLPro is a specialized system for ceded reinsurance — insurance that one company buys from another to spread risk.

Example: An insurance company insures 100 houses. To reduce risk, they buy reinsurance from a larger company for 50 of those houses. XLPro manages that reinsurance relationship.

XLPro Key Features:

  • Manages reinsurance contracts and coverage
  • Tracks claims that are reinsured
  • Calculates recoveries from reinsurers
  • Handles financial reporting
Why integrate with Xuber? Xuber handles the original claims. When Xuber sends claims data to XLPro, the reinsurance team knows exactly which claims are covered by reinsurance and what the company can recover.

How Does XLPro Integration Work?

The integration has three main components:

  1. XLPro Integration Service — Installed on Xuber Enterprise server
  2. Messaging Module — On Xuber Messaging server, passes data between systems
  3. USM 6-9 Load — On XLPro database server, processes incoming messages

Data Flow:

Xuber Enterprise → Messaging Server → Staging Database → XLPro Database

Data moves through a temporary "staging" database where it's validated before reaching XLPro.

Why staging? The staging database acts like a quality checkpoint. Data is checked for errors before it enters XLPro, preventing bad data from corrupting the reinsurance system.

What Do You Need Before Installing?

System Requirements:

  • GLOBAL XLPro version 2.8.30 or later
  • Xuber Enterprise with messaging components
  • Microsoft SQL Server (supported version for XLPro)
  • SQL Server Integration Services (SSIS)
  • MSDTC (Distributed Transaction Coordinator)

Access and Permissions:

  • Admin access to SQL Server
  • Administrator rights on Xuber servers
  • db_owner permissions on databases
Installation Plan: You'll need installation files from Xuber Enterprise media, database access, and server admin rights. Back up all databases before starting.

Installation Overview (5 Main Steps)

Step 1: Update the GLOBAL XLPro database with XLPro Integration schema and tables

Step 2: Update the Xuber Enterprise database with integration configuration

Step 3: Run XLPro Integration installer on Xuber Enterprise server

Step 4: Install XLPro Messaging module on messaging server

Step 5: Install and configure USM 6-9 Load on XLPro database server

Total time: 2-4 hours depending on system complexity

Key principle: Always update databases first, then install services. Back up databases after each major step.

Key Concepts to Remember

1. SSIS Packages

SSIS (SQL Server Integration Services) packages are jobs that move and transform data. Two packages handle the integration:

  • USM2Staging — Moves data from Xuber to staging database
  • Staging2XLPro — Moves validated data from staging to XLPro

2. Configuration Files

Config files (.dtsConfig) tell the SSIS packages where databases are located and how to connect to them.

3. Service Accounts

Integration services run under specific service accounts with limited permissions — this is safer than using admin accounts.
