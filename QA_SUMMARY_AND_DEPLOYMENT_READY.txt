================================================================================
KNOWN LIMITATIONS (Not Issues)
================================================================================

1. Progress per-browser only
   - Quiz scores don't sync across devices
   - Intentional design choice (privacy, simplicity)
   - Workaround: Manual export of scores if needed

2. No user authentication
   - All users are anonymous
   - Intentional design (reduces maintenance)
   - Progress is device-specific

3. Limited TTS on Firefox
   - Web Speech API has limited Firefox support
   - Modules still fully functional without TTS
   - Alternative: Users can use browser extensions

4. No analytics built-in
   - Can't track which modules are most popular
   - Optional: Google Analytics can be added later
   - Workaround: GitHub Insights shows traffic

5. No centralized progress reporting
   - Can't generate team completion reports
   - Intentional design (privacy, simplicity)
   - Workaround: Manual surveys if needed

These are NOT blockers — they are trade-offs for simplicity and no backend.
