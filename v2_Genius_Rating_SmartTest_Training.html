Concept 1

How Genius Rates Risk

Base rates, factors, loadings, discounts and IPT - how they combine to produce a premium

Rating is the process of calculating the premium for an insurance policy. Genius applies base rates, risk factors, loadings and discounts according to rules configured in Genius Admin. The order matters.

Rating components

Base Rate

Starting point

The fundamental rate for the product and cover type. Set per product and often per risk category.

Rating Factors

Multipliers

Each underwriting variable (vehicle age, claims history) has a factor table that adjusts the base rate up or down.

Loadings

Flat additions

Fixed amount additions to premium - for example a policy fee or endorsement loading.

Discounts

Reductions

Percentage or flat reductions - multi-policy discount, loyalty discount, broker introductory rate.

Minimum Premium

Floor

The minimum amount charged regardless of calculated premium. Prevents technically-valid ratings from producing impractical premiums.

IPT

Insurance Premium Tax

Tax applied to the net premium at the current standard rate. Genius applies this automatically based on cover type.

Calculation sequence

1. Base Rate selected for product
2. Each factor applied in configured order
3. Loadings added
4. Discounts applied
5. Minimum premium check
6. IPT calculated on net premium
Factor order matters. Genius applies factors in the order they are configured. Changing the order changes the premium calculation even with identical factor values.

Concept 2

Configuring Rating in Genius Admin

Creating and modifying rating structures, factor tables and effective dates

Rating structures are configured in Genius Admin. Changes take effect immediately in the environment. Always test in UAT before applying to production and always use effective dates.

Navigation

1

Access Genius Admin

Log in to Genius Admin - separate URL from main Genius. Navigate to Products, select the product, then Rating.

2

Select the cover section

Each cover section has its own rating structure. Select the cover type to see its components.

3

Edit base rates with effective dates

Base Rates tab, select rate set, edit cells. Use effective dates to schedule changes - the old rate stays active until the effective date.

4

Edit factor tables

Factors tab, select the factor, edit the table. Factor values are keyed by underwriting variable value - for example Claims History 0 equals 1.00, 1 equals 1.15.

Never change a base rate with an immediate effective date in production without explicit client instruction and CAB approval. Rate changes affect every new quotation from that moment. Use a future effective date.
Rating history: Genius Admin keeps a full history of all rating changes with timestamps and the user who made them. If a premium looks wrong after a change, review the history to see exactly what changed and when.
Test in UAT first: Make the rating change in UAT. Run test scenarios. Confirm results match expected premiums. Only then apply to production through the change process.

Concept 3

SmartTest PTF Regression

Running the cumulative PTF regression suite and interpreting results for Genius deployments

Every PTF bundle deployed to a Genius environment must pass SmartTest regression before being approved for promotion. The Genius team owns the result review as they know which scenarios are business-critical.

Running SmartTest

1

Confirm PTF is deployed

Verify the PTF has been applied to the target iSeries environment. Log in to Genius to confirm the correct version is showing.

2

Open SmartTest Manager

Start SmartTest Manager. Select Environment (for example GENIUSQAL). Select Suite: GeniusPTFRegression.

3

Run the suite

Click Run All. Do not log in to Genius manually during the run - it causes timing failures. Full suite takes approximately 25 minutes.

4

Review the HTML report

Open C:\SmartTest\Reports\[timestamp]\index.html. Green is pass, red is fail. Click each failure to see the screenshot diff.

Failure classification

False positive - can proceed

Environment noise

Date or time changed. Sequential reference incremented. Timing issue. Cosmetic text change. Previously known noise.

Genuine regression - escalate

Real defect

Error message appeared where none before. Wrong premium or reserve calculated. Workflow went to wrong screen. Multiple related scripts failed.

If all scripts fail immediately after a PTF deployment with an error screen, the PTF installation likely failed or is incomplete. Fix the PTF first - do not attempt to interpret SmartTest results from a broken environment.
