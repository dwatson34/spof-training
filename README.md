## 💾 Install Your Own Copy

Want to deploy your own version to GitHub Pages? It takes 5 minutes:

1. Create a GitHub repository called `spof-training`
2. Upload all 26 files (HTML modules + docs)
3. Go to repository Settings → Pages → select `main` branch
4. GitHub Pages is now enabled!

Your portal will be live at: `https://your-username.github.io/spof-training/`

See the **Deployment Guide** in Documentation for step-by-step instructions.

## ❓ FAQ

**Can I retake a module?**  
Yes! Retake any module as many times as you want. Your latest score is recorded.

**Where are my quiz scores saved?**  
In your browser's localStorage. They persist if you close and reopen the browser, but clear if you delete browser data.

**Can I download the modules?**  
All modules are self-contained HTML files. You can save them and use them offline.

**How do I add a new module?**  
Copy an existing module, edit the content and quiz, and upload to your GitHub repository. See the Module Template in Documentation for detailed instructions.

**What if I find a bug?**  
Open an issue on GitHub: https://github.com/dwatson34/spof-training/issues

**Does this cost anything?**  
No! GitHub Pages hosting is completely free.
